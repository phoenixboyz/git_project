# GIT COMMANDS

## 0. (git init) helps to initialize a project to git.
## 1. (git status) helps to check the status change of your project.
## 2. (git add .) helps to track the project, if you see a color text that is red then it means that the file you have editted or the folder that you have created is not tracked, if you see that a file or folder is green then it means that git is tracking them.
## 3. (git commit -m"Update/Commit message") helps to add a mark or commit message to what ever update you did on the project.
## 4. (git push) helps to upload our project to github, it also helps to upload updates that we have maede to github as well.
## 5. (git clone project_ssh_url) helps to download a project from github.
## 6. (git pull) helps to pull/get updates from a collaborator or a fellow developer.
## 7. (git branch your_branch_name) helps to create a new branch "folder within git"
## 8. (git branch) helps to check the current branch that we are on, if you see an * and a green text then that is the current branch that you are on.
## 9. (git checkout your_branch_name) help to move to another branch "folder within git"
## 10. (git branch -D your_branch_name) helps to delete a branch "folder within git"
## 11. (git merge the_branch_you_want_to_copy_your_update_from) helps to copy update from 1 branch to another, before you do git merge or before you merge something into another branch, make sure that you do git status, if there is an untracked progress commit them before you merge your update, lastly before you merge also ensure that you are at the branch that needs the update, you must NOT be in the branch that has the update, you should be in the  branch that needs the update so that when you merge it will be available.
