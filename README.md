# GIT COMMANDS

## 0. (git init) helps to initialize a project to git.
## 1. (git status) helps to check the status change of your project.
## 2. (git add .) helps to track the project, if you see a color text that is red then it means that the file you have editted or the folder that you have created is not tracked, if you see that a file or folder is green then it means that git is tracking them.
## 3. (git commit -m"Update/Commit message") helps to add a mark or commit message to what ever update you did on the project.
## 4. (git push) helps to upload our project to github, it also helps to upload updates that we have maede to github as well.
## 5. (git clone project_ssh_url) helps to download a project from github.
## 6. (git pull) helps to pull/get updates from a collaborator or a fellow developer.
